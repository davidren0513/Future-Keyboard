# Future Keyboard 0.6.0 · 测试版

永不联网，安心输入。原生 Android 隐私输入法，支持 Android 8.0+。

## 本版新增

- 首音节完整单字候选，词组找不到时可逐字组合；本地学习开启时保存完整词组。
- 候选栏右侧展开箭头，键盘区域展示五列多行候选，可上下滚动。
- Emoji 扩充至八个分类、867 项。
- 保留中文九宫格 / 全键盘、中英文离线词语联想、本地词频、快捷工具栏和液态玻璃外观。

## 隐私

无网络权限、无账号或云同步，不上传输入内容。个人词组仅保存在本机，可关闭学习或清空；密码及宿主禁止个性化学习的输入不学习。确认上屏的文字仍会交给当前宿主应用，后者行为由其自身规则决定。

## 附件

- `FutureKeyboard-v0.6.0-debug.apk`：debug 测试签名安装包。
- `SHA256SUMS`：安装包与词库源文件归档的 SHA-256 校验。
- `dictionary-source-v0.6.0.zip`：随包词库对应的固定版上游 YAML、许可与来源说明。

这是测试版，尚未覆盖全部品牌设备。跨窗口实时模糊需要 Android 12+ 和系统支持；不支持时使用深色底板。英文搭配表仍较基础，不做整句生成。

不同开发机或 CI 的 debug 签名可能不同；升级请先核对签名。仓库不公开签名私钥，本版不代表正式商店发行签名。

## 验证

18 项 JVM 测试、19 项模拟器交互检查、Android Lint 和 APK 离线权限审计通过。真实设备、所有 Android 版本及布局组合未全面验证，详见仓库 `docs/VALIDATION.md`。
