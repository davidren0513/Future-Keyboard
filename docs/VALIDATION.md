# 验证范围与截图来源

## 本地版本 0.6.0

验证环境为 Android 15 / API 35 ARM64 模拟器，1080×2400、density 440。以下为专用模拟器结果，不能代表所有真机与系统。

- 18 项 JVM 单元测试通过，涵盖完整拼音、T9、常用词、单字候选不截断、明确分词、逐字消耗范围、组词持久化及个性化隔离、英文补全 / 后续词。
- 19 项交互检查通过，涵盖全键盘与九宫格展开候选、收起保留拼音、选择生僻字后保留剩余拼音、完整组词与再次输入、恢复键盘、Emoji 分类 / 插入 / 完整删除、设置快捷入口。
- Debug 构建和 Android Lint 通过。
- 最终 APK 无 `INTERNET` / `ACCESS_NETWORK_STATE` 权限，运行时代码的预设网络 / 浏览器入口静态检查通过，备份排除规则存在。

本次 GitHub 发布整理再次运行构建、18 项 JVM 测试、Lint 及最终 APK 离线审计。此前 19 项交互记录保留为验证依据，文档 / CI 整理没有重复声明为新的全设备测试。

## 未全面验证

- 多品牌真机、厂商输入法限制和所有 Android 版本。
- 横屏、大字体、分屏及全部宿主应用组合。
- 完整 TalkBack 用户流程与全部无障碍场景。
- 长期用户词频表现、英文搭配覆盖、完整语言模型；项目不提供整句生成。
- 正式发行签名和商店上架。

实时背景模糊依赖系统支持及开关，设备、宿主背景与系统合成策略会影响效果。自动权限审计是回归检查，不等同于完整安全审计。
