# 隐私说明

Future Keyboard 是永不联网的 Android 输入法。本文适用于当前 0.6.0 实现。

## 应用如何运行

- 不申请 `INTERNET` 或 `ACCESS_NETWORK_STATE` 权限；Manifest 合并时显式移除这两项权限。
- 拼音解码、候选计算、词语补全及组词学习均在本机处理。
- 没有账号、服务端、广告 SDK、分析 SDK或云同步。
- 没有应用内 WebView 或外部浏览器跳转；关于页地址仅作文字展示，许可随安装包保存。
- 词语联想只使用本轮最后确认词作为上下文，不读取整段聊天历史，不建立整段输入记录。英文插入后续词时只检查光标前一个字符，以避免重复空格；删除刚插入的组合 Emoji 时仅核对相应长度的字符。

文字上屏后会交给当前宿主应用。宿主应用的存储与网络行为不属于本输入法控制范围。

## 本地词组保存什么

开启学习后，本机私有目录保存选中的词组、对应拼音、使用次数和最近使用时间。一个拼音缓冲内分次选字完成的完整组合也可保存。

最多保留 5,000 条个人词组，超过上限按最近使用情况淘汰。不会保存整段聊天记录。词组记忆和自定义词组排除 Android 云备份与设备迁移。

密码字段或宿主应用设置 `IME_FLAG_NO_PERSONALIZED_LEARNING` 时，不使用或写入个人词条。

## 用户如何控制

「本地词组」中关闭学习会保留已存记录，但不再使用或新增个人词条；选择清空才删除个人词频和自定义词组。内置字词不受影响。卸载并删除应用数据同样会删除本地记录。

「键盘与触感」中可以关闭离线词语联想，中文拼音候选仍可正常使用。输入法不提供联网开关。

## 如何核查

构建后运行 `python3 scripts/verify_offline.py`。脚本检查最终 APK 权限，并静态检查运行时代码中若干网络或浏览器入口。它是自动回归检查，不替代完整安全审计。

开发机获取构建工具、词典源文件或运行 GitHub Actions 会联网，这些行为发生在开发环境，不属于安装后应用的运行行为。官网和开源地址在 GitHub 文档中可以点击，应用内则没有外链跳转。
